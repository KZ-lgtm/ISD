Intelligent Spray — Interactive Demo

A hands-on, browser-only reproduction of the "Combine" and "Pre-run" steps from a real manufacturing-execution-system feature that guides a spray-painting robot: build a reusable recipe (image + path + a trackable feature), then simulate a workpiece that has shifted and watch real computer vision measure the deviation and correct the path.

Runs 100% locally in your browser — no server, no upload

1 Combine — Build a Recipe

Drag a spray-path preset onto the reference photo, then mark a small, distinctive area as the "feature region" — the patch of the image the vision system will later search for. Save the result as a named recipe.

    2 Pre-run — Match & Correct

    Load a saved recipe, then either generate a simulated "current photo" (the workpiece nudged by a known amount, so you can check the math) or upload your own photo. Run the match to detect real ORB features, filter them with a RANSAC-fit rigid transform, and apply the measured deviation to the saved path.

    3 Corrected Path

    How this demo is built

    This page runs real ORB feature detection + BFMatcher (via OpenCV.js/WebAssembly, compiled to run entirely client-side) and a hand-written RANSAC-fit rigid transform to estimate translation and rotation between two images — the same class of algorithm the production system runs server-side in C# against a live ABB robot and a Hikrobot GigE camera. Nothing here is faked or pre-recorded: the images are drawn live on <canvas>, and every match runs fresh in your browser. The full production system additionally drives real robot motion (RAPID variable writes with mastership handling and read-back verification), which this static demo intentionally leaves out.
